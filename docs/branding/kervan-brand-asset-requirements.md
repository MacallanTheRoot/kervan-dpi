# Kervan brand asset requirements — design brief, not an approved identity

Historical Phase 8A brief. The blue camel PNG located in STEP 02 and its
derived Windows assets are recorded in [kervan-camel-source.md](kervan-camel-source.md).
The source-rights and native visual review gates in this brief remain relevant.

## Current pipeline

The current `assets/icon.png` is a 128 × 128 RGBA PNG showing a white shield on a blue rounded square. `assets/icon.ico` contains 16, 24, 32, 48, 64 and 128 px PNG frames generated by `packaging/generate_icon.py`. The same PNG supplies the Qt window/taskbar/tray icon, 36 × 36 header mark and Linux hicolor 128 × 128 desktop icon. The ICO supplies the Windows PyInstaller EXE icon. Debian packaging copies the PNG under the stable `goodbyedpi-turkey` icon ID. There is no separate About-screen artwork; About uses text. Existing assets remain in use until approval, and their authorship/license should be verified before a new public brand release.

## Deliverables for approved design

| Surface | Needed master/export | Constraint |
| --- | --- | --- |
| Master mark | Editable SVG with outlined fonts and documented color values | Legible at 16 px; no engine/vendor marks or implied VPN shield promise |
| Windows EXE | Multi-size ICO: 16, 24, 32, 48, 64, 128 and ideally 256 px, 32-bit alpha | Check taskbar, UAC, Explorer and high-DPI scaling on native Windows |
| Qt window, tray and header | Transparent PNG exports at 16/24/32/36/48/64/128/256 px or approved SVG runtime asset | Test light and dark panels and monochrome tray environments; retain accessible text |
| Linux desktop and Debian icon | hicolor PNG 128 × 128 minimum; ideally 16/24/32/48/64/128/256/512 px and scalable SVG | Keep current icon ID until package/desktop migration; verify menu cache and one launcher |
| About | Optional approved mark and wordmark, plus text-only fallback | Preserve current dialog accessibility and backend attribution |
| Future GitHub Pages | SVG wordmark, favicon ICO/PNG, social preview 1200 × 630 PNG | Separate publication and site approval |
| Future Android | Adaptive icon foreground/background vector or PNG, 108 × 108 dp safe-zone design; Play listing exports | Separate application identity and mobile project approval |
| Future iOS | Opaque 1024 × 1024 PNG App Store icon plus platform asset catalog exports | No alpha in store icon; separate mobile approval |

Design character: mostly modern professional technology, with Turkish cultural cues and a small amount of subtle character. The mark must work without fine lines at 16 px, remain recognizable in grayscale, and avoid misleading symbols of encryption, IP masking or system-wide protection. Produce light/dark and high-contrast samples. Check color contrast, color-blind distinguishability and visual weight against the current Qt layout without redesigning that layout.

Deliver editable source, exported raster/vector files, designer attribution, written assignment or compatible license, third-party font/shape licenses and permission for modification and distribution. Keep provenance and hashes in the future asset review. Do not use stock art or generated provisional logos as release identity. Approval and brand clearance precede replacement of the current icon files.
